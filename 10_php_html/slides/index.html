10 - PHP & HTML

Dynamische Webseiten erzeugen

Lernziele dieser Lektion

  • PHP und HTML in einer Datei kombinieren und die Kurzschreibweise <?= ?> einsetzen können
  • Mit Schleifen und Bedingungen (alternative Syntax) HTML-Listen und -Tabellen aus Arrays erzeugen können
  • Ausgaben mit htmlspecialchars() gegen XSS absichern können
  • Wiederkehrende Seitenteile mit require in eigene Dateien auslagern können
  • Links mit URL-Parametern erzeugen und auswerten können
Rückblick

Wo stehen wir?

Bisher

Wir haben mit echo vor allem einzelne Werte ausgegeben - Text ohne Struktur

Heute

PHP erzeugt ganze HTML-Seiten: Listen, Tabellen und Links aus unseren Daten

Grundlage für die nächsten Lektionen: Formulare, Validierung und Dateien bauen alle darauf auf

Grundlagen

PHP-Modus und HTML-Modus

  • Alles ausserhalb von <?php ... ?> wird unverändert an den Browser gesendet
  • Alles innerhalb wird auf dem Server ausgeführt - nur die Ausgabe landet im HTML 
                    
                        <?php $name = "Anna"; ?>
                        <h1>Willkommen</h1>
                        <p>Hallo <?php echo $name; ?></p>
                        <p>Heute ist ein schöner Tag.</p>
                        <?php echo "<p>Tschüss!</p>"; ?>

Man kann beliebig oft zwischen PHP und HTML hin und her wechseln

Grundlagen

Was kommt im Browser an?

index.php (auf dem Server)

                    
                        <?php $name = "Anna"; ?>
                        <h1>Willkommen</h1>
                        <p>Hallo <?php echo $name; ?></p>

Antwort (im Browser)

                    
                        <h1>Willkommen</h1>
                        <p>Hallo Anna</p>

Tipp: Mit Ctrl + U zeigt der Browser den Seitenquelltext an - dort sieht man genau, welches HTML PHP erzeugt hat

Grundlagen

Kurzschreibweise <?=

Für einzelne Ausgaben gibt es eine kürzere Schreibweise - sie entspricht <?php echo ...; ?>

lang

                    
                        <p>Hallo <?php echo $name; ?></p>

kurz

                    
                        <p>Hallo <?= $name ?></p>

Hinter <?= darf ein beliebiger Ausdruck stehen, z.B. <?= $preis * 2 ?> - ein Semikolon ist nicht nötig

Grundlagen

HTML in Strings oder HTML mit PHP?

HTML in echo

                    
                        <?php
                        echo "<h2>" . $titel . "</h2>";
                        echo "<p class=\"info\">" . $text . "</p>";

Unübersichtlich, Anführungszeichen müssen maskiert werden

PHP im HTML

                    
                        <h2><?= $titel ?></h2>
                        <p class="info"><?= $text ?></p>

Lesbar, der Editor erkennt das HTML

Faustregel: Viel HTML mit wenig PHP → PHP ins HTML einbetten, nicht umgekehrt

Quiz

Was sieht man im Seitenquelltext?

                    
                        <?php $preis = 4.5; // Kommentar A ?>
                        <!-- Kommentar B -->
                        <p>Preis: <?= $preis * 2 ?> CHF</p>

<!-- Kommentar B --> und <p>Preis: 9 CHF</p> - der PHP-Kommentar A bleibt auf dem Server, der HTML-Kommentar B wird mitgeschickt

Schleifen

Listen mit foreach erzeugen

Die Schleife kann mitten im HTML beginnen und enden - alles dazwischen wird pro Durchlauf ausgegeben 

                    
                        <?php $farben = ["Rot", "Grün", "Blau"]; ?>

                        <ul>
                            <?php foreach ($farben as $farbe) { ?>
                                <li><?= $farbe ?></li>
                            <?php } ?>
                        </ul>

Funktioniert, aber die einzelne Klammer <?php } ?> ist schwer zu lesen - welche Schleife endet hier?

Schleifen

Alternative Syntax

Statt { } schreibt man einen Doppelpunkt und beendet den Block mit endforeach; 

                    
                        <ul>
                            <?php foreach ($farben as $farbe): ?>
                                <li><?= $farbe ?></li>
                            <?php endforeach; ?>
                        </ul>
AnweisungBeginnEnde
foreachforeach (...):endforeach;
forfor (...):endfor;
ifif (...):endif;
Praxis

Tabelle aus einem Array

                    
                        <?php
                        $produkte = [
                            ["name" => "Äpfel", "preis" => 3.5],
                            ["name" => "Brot", "preis" => 6.5],
                        ];
                        ?>
                        <table>
                            <?php foreach ($produkte as $p): ?>
                                <tr>
                                    <td><?= $p["name"] ?></td>
                                    <td><?= number_format($p["preis"], 2) ?> CHF</td>
                                </tr>
                            <?php endforeach; ?>
                        </table>

number_format($zahl, 2) gibt eine Zahl mit 2 Nachkommastellen aus, z.B. 3.50

Bedingungen

Bedingungen im HTML

Auch if / else gibt es in der alternativen Syntax - damit werden ganze HTML-Blöcke ein- oder ausgeblendet 

                    
                        <?php if ($p["vorrat"] === 0): ?>
                            <span class="leer">Ausverkauft</span>
                        <?php elseif ($p["vorrat"] < 5): ?>
                            <span>Nur noch <?= $p["vorrat"] ?> Stück</span>
                        <?php else: ?>
                            <span>An Lager</span>
                        <?php endif; ?>
Praxis

Dynamische Attribute

PHP kann auch Werte innerhalb von HTML-Attributen erzeugen, z.B. CSS-Klassen oder Links 

                    
                        <tr class="<?= $p["vorrat"] === 0 ? "leer" : "" ?>">
                            <td><?= $p["name"] ?></td>
                        </tr>

                        <img src="bilder/<?= $p["bild"] ?>" alt="<?= $p["name"] ?>">

Die doppelten Anführungszeichen innerhalb von <?= ?> sind kein Problem: PHP wird zuerst ausgeführt, der Browser sieht nur das Ergebnis, z.B. class="leer"

Quiz

Wie viele <li> entstehen?

                    
                        <?php $zahlen = [3, 8, 1, 6]; ?>
                        <ul>
                        <?php foreach ($zahlen as $z): ?>
                            <?php if ($z > 4): ?>
                                <li><?= $z ?></li>
                            <?php endif; ?>
                        <?php endforeach; ?>
                        </ul>

Zwei: <li>8</li> und <li>6</li> - nur Zahlen grösser als 4 erzeugen einen Listeneintrag

Sicherheit

Gefahr: Eingaben direkt ausgeben

                    
                        <?php $name = $_GET["name"] ?? "Gast"; ?>
                        <p>Hallo <?= $name ?></p>

Aufruf mit index.php?name=<script>alert('Hack')</script>

Der Browser führt das eingeschleuste JavaScript aus. Das nennt man Cross-Site-Scripting (XSS) - so können z.B. Session-Cookies gestohlen werden

Sicherheit

htmlspecialchars()

Wandelt Zeichen mit Sonderbedeutung in HTML in harmlose Entities um - der Browser zeigt sie nur noch als Text an

Zeichenwird zu
<&lt;
>&gt;
&&amp;
"&quot;
'&#039;
 
                    
                        <?= htmlspecialchars($name) ?>

Regel: Alles, was von aussen kommt (URL, Formular, Datei), bei der Ausgabe immer maskieren

Praxis

Kurze Hilfsfunktion e()

htmlspecialchars() ist lang und wird oft gebraucht - eine eigene Funktion (vgl. Lektion 05) spart Schreibarbeit 

                    
                        <?php
                        function e(string $text): string
                        {
                            return htmlspecialchars($text);
                        }
                        ?>
                        <p>Hallo <?= e($name) ?></p>
                        <a href="profil.php?name=<?= e($name) ?>">Profil</a>

Der Name e() (für "escape") ist eine verbreitete Konvention, z.B. im Framework Laravel

Quiz

Was zeigt der Browser an?

                    
                        <?php
                        $name = "<b>Anna</b>";
                        echo "<p>" . htmlspecialchars($name) . "</p>";

Den Text <b>Anna</b> inklusive der spitzen Klammern, nicht fett. Nur der Inhalt von $name wird maskiert, das <p> bleibt ein echter Absatz

Dateien

Wiederkehrende Teile auslagern

Kopf, Navigation und Fusszeile sind auf jeder Seite gleich - statt sie zu kopieren, lagert man sie in eigene Dateien aus

header.php
<!DOCTYPE html>, <head>, Navigation
+
index.php
der eigentliche Inhalt der Seite
+
footer.php
Fusszeile, </body></html>

Änderungen am Layout müssen so nur noch an einer Stelle gemacht werden

Dateien

Dateien einbinden mit require

index.php

                    
                        <?php
                        $title = "Startseite";
                        require "header.php";
                        ?>
                        <p>Willkommen!</p>
                        <?php require "footer.php"; ?>

header.php

                    
                        <!DOCTYPE html>
                        <html lang="de">
                        <head>
                            <title><?= $title ?></title>
                        </head>
                        <body>

Die eingebundene Datei wird an dieser Stelle eingefügt und sieht alle Variablen, die vorher definiert wurden (hier $title)

Dateien

include oder require?

BefehlWenn die Datei fehlt ...
includeWarnung, das Skript läuft weiter
requireFehler, das Skript bricht ab
require_oncewie require, bindet die Datei aber höchstens einmal ein

Für Dateien, ohne die die Seite nicht funktioniert, immer require verwenden. require_once eignet sich für Dateien mit Funktionen oder Klassen, die nicht doppelt definiert werden dürfen

Praxis

Aufbau einer PHP-Seite

                    
                        <?php
                        // 1. Logik: Daten laden, Eingaben verarbeiten
                        session_start();
                        require_once "funktionen.php";
                        $produkte = ladeProdukte();
                        $title = "Produkte";
                        // 2. Ausgabe: nur noch HTML mit wenig PHP
                        require "header.php";
                        ?>
                        <ul>
                            <?php foreach ($produkte as $p): ?>
                                <li><?= e($p["name"]) ?></li>
                            <?php endforeach; ?>
                        </ul>

Logik oben, Ausgabe unten: so steht session_start() garantiert vor der ersten Ausgabe

Praxis

Links mit URL-Parametern

Jedes Produkt verlinkt auf eine Detailseite - der Index im Array wird als Parameter id mitgegeben 

                    
                        <?php foreach ($produkte as $id => $p): ?>
                            <li>
                                <a href="produkt.php?id=<?= $id ?>">
                                    <?= e($p["name"]) ?>
                                </a>
                            </li>
                        <?php endforeach; ?>

Ergibt z.B. <a href="produkt.php?id=1">Brot</a>

Praxis

Die Detailseite

                    
                        <?php
                        require_once "daten.php"; // enthält $produkte
                        $id = (int) ($_GET["id"] ?? -1);
                        $produkt = $produkte[$id] ?? null;
                        ?>
                        <?php if ($produkt === null): ?>
                            <p>Produkt nicht gefunden.</p>
                        <?php else: ?>
                            <h1><?= e($produkt["name"]) ?></h1>
                            <p><?= number_format($produkt["preis"], 2) ?> CHF</p>
                        <?php endif; ?>
                        <a href="index.php">Zurück zur Übersicht</a>

URL-Parameter kann jeder beliebig ändern - immer mit einem ungültigen Wert rechnen (z.B. ?id=999)

Achtung

Typische Fehler

endforeach vergessen

Führt zu unexpected end of file - der Fehler wird in der letzten Zeile gemeldet

; statt :

Nach foreach (...) und if (...) folgt ein Doppelpunkt

Ausgabe nicht maskiert

Daten von aussen ohne htmlspecialchars() → XSS

Falscher Pfad

Tippfehler im Dateinamen bei require → Abbruch

TL;DR

  • Alles ausserhalb von <?php ?> geht unverändert an den Browser; <?= $x ?> gibt einen Wert aus
  • Die alternative Syntax (foreach (...): ... endforeach;, if (...): ... endif;) macht Schleifen und Bedingungen im HTML lesbar
  • Daten von aussen immer mit htmlspecialchars() ausgeben - sonst droht XSS
  • require bindet wiederkehrende Teile wie Header und Footer ein
  • Links mit ?id=... übergeben Werte an die nächste Seite - nächste Lektion: Formulare

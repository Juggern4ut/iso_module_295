11 - Formulare

Eingaben der Benutzer verarbeiten

Lernziele dieser Lektion

  • Erklären können, wie Formulardaten vom Browser zum PHP-Skript gelangen (action, method, name)
  • Den Unterschied zwischen GET und POST kennen und passend einsetzen können
  • Eingaben mit $_GET und $_POST auslesen und prüfen können, ob ein Formular abgeschickt wurde
  • Textfelder, Auswahllisten, Radio-Buttons und Checkboxen in PHP auswerten können
  • Eingaben nach dem Absenden wieder im Formular anzeigen können
Rückblick

Wo stehen wir?

Lektion 10

Werte über Links an PHP übergeben, z.B. produkt.php?id=2 - die URL haben wir erzeugt

Heute

Die Benutzer geben die Werte selbst ein - der Browser schickt sie per Formular an unser Skript

Formulare sind die wichtigste Art, wie Daten von aussen in eine Webapplikation gelangen: Login, Suche, Bestellung, Kontakt, ...

Repetition HTML

Ein Formular in HTML

                    
                        <form action="danke.php" method="post">
                            <label for="vorname">Vorname</label>
                            <input type="text" id="vorname" name="vorname">

                            <label for="email">E-Mail</label>
                            <input type="email" id="email" name="email">

                            <button type="submit">Senden</button>
                        </form>

Aus HTML bekannt - für PHP zählen vor allem drei Dinge: action, method und name

Grundlagen

Die drei wichtigen Attribute

action

Wohin werden die Daten geschickt? Die URL des PHP-Skripts. Fehlt sie, geht es an die aktuelle Seite

method

Wie werden die Daten geschickt? get (Standard) oder post

name

Unter welchem Schlüssel landet der Wert in $_GET bzw. $_POST?

Ein Feld ohne name wird nicht mitgeschickt - die id ist nur für <label> und CSS

Grundlagen

Vom Formular zum PHP-Skript

Browser
Benutzer füllt das Formular aus und klickt auf Senden
→
Request
vorname=Anna&email=anna@example.ch
→
PHP
$_POST["vorname"]
enthält "Anna"

Der Browser baut aus allen Feldern Paare name=wert - PHP legt sie automatisch in einem assoziativen Array ab

GET

Formular mit method="get"

suche.php

                    
                        <form action="suche.php" method="get">
                            <input type="search" name="q">
                            <button>Suchen</button>
                        </form>

                        <?php if (isset($_GET["q"])): ?>
                            <p>Gesucht: <?= e($_GET["q"]) ?></p>
                        <?php endif; ?>

URL nach dem Absenden

                    
                        suche.php?q=Birnen

Genau wie unsere Links aus Lektion 10 - die Werte stehen sichtbar in der URL

POST

Formular mit method="post"

login.php

                    
                        <form action="login.php" method="post">
                            <input type="text" name="user">
                            <input type="password" name="pass">
                            <button>Login</button>
                        </form>

                        <?php
                        $user = $_POST["user"] ?? "";
                        $pass = $_POST["pass"] ?? "";

URL nach dem Absenden

                    
                        login.php

Die Daten werden im Body des Requests geschickt - in den DevTools unter Netzwerk → Payload sichtbar

Vergleich

GET oder POST?

GETPOST
Daten stehenin der URLim Body des Requests
Lesezeichen / Link teilenmöglichnicht möglich
Im Verlauf / Server-Logjanein
Datenmengebegrenzt (URL-Länge)gross
EinsatzDaten abfragen: Suche, FilterDaten ändern: Login, Bestellung

POST ist nicht verschlüsselt - nur weniger sichtbar. Für Sicherheit sorgt erst HTTPS

Quiz

Was enthält $_POST?

                    
                        <form method="post">
                            <input type="text" id="vorname">
                            <input type="text" name="nachname">
                            <button>Senden</button>
                        </form>

Eingabe: Vorname "Anna", Nachname "Meier"

Nur ["nachname" => "Meier"] - das erste Feld hat kein name-Attribut und wird nicht mitgeschickt

Verarbeitung

Wurde das Formular abgeschickt?

Beim ersten Aufruf ist $_POST leer - die Verarbeitung soll erst nach dem Absenden laufen 

                    
                        <?php
                        if ($_SERVER["REQUEST_METHOD"] === "POST") {
                            $vorname = $_POST["vorname"] ?? "";
                            // ... Eingaben verarbeiten
                        }

$_SERVER["REQUEST_METHOD"] enthält "GET" beim normalen Aufruf der Seite und "POST" nach dem Absenden eines POST-Formulars

Praxis

Alles in einer Datei

                    
                        <?php
                        $gesendet = false;
                        if ($_SERVER["REQUEST_METHOD"] === "POST") {
                            $vorname = $_POST["vorname"] ?? "";
                            $gesendet = true;
                        }
                        ?>
                        <?php if ($gesendet): ?>
                            <p>Danke, <?= e($vorname) ?>!</p>
                        <?php else: ?>
                            <form method="post"> ... </form>
                        <?php endif; ?>

Ohne action schickt das Formular an sich selbst - so bleiben Formular und Verarbeitung übersichtlich zusammen

Eingabefelder

Was kommt in PHP an?

Feldgesendet wird
<input type="text">, <textarea>der eingegebene Text (evtl. "")
<input type="number">die Zahl - aber als String, z.B. "3"
<select>das value der gewählten <option>
<input type="radio">das value des gewählten Buttons - nichts, wenn keiner gewählt ist
<input type="checkbox">das value, wenn angehakt - sonst nichts
Eingabefelder

Auswahlliste und Radio-Buttons

Optionen aus einem Array

                    
                        <select name="produkt">
                            <?php foreach ($produkte as $id => $p): ?>
                                <option value="<?= $id ?>">
                                    <?= e($p["name"]) ?>
                                </option>
                            <?php endforeach; ?>
                        </select>

Gleicher name = eine Gruppe

                    
                        <input type="radio"
                               name="lieferung"
                               value="abholen"> Abholen
                        <input type="radio"
                               name="lieferung"
                               value="post"> Per Post

In PHP kommt nur das value an, nicht der angezeigte Text: z.B. $_POST["produkt"] → "2", $_POST["lieferung"] → "post"

Eingabefelder

Checkboxen

                    
                        <input type="checkbox" name="newsletter" value="ja">

                        <?php
                        // true, wenn angehakt - sonst false
                        $newsletter = isset($_POST["newsletter"]);

Angehakt

$_POST["newsletter"] ist "ja"

Nicht angehakt

Der Schlüssel "newsletter" existiert nicht

$_POST["newsletter"] ohne isset() oder ?? führt zur Warnung Undefined array key

Eingabefelder

Mehrere Werte mit name="...[]"

                    
                        <input type="checkbox" name="extras[]"
                               value="geschenk"> Geschenkpapier
                        <input type="checkbox" name="extras[]"
                               value="karte"> Grusskarte
                        <input type="checkbox" name="extras[]"
                               value="express"> Express
                    
                
                    
                        <?php
                        $extras = $_POST["extras"] ?? [];
                        // z.B. ["geschenk", "express"]
                        foreach ($extras as $extra) {
                            echo e($extra) . "<br>";
                        }

Die eckigen Klammern im name sagen PHP: Sammle alle Werte in einem Array. Ist nichts angehakt, fehlt der Schlüssel - darum ?? []

Quiz

Was gibt dieser Code aus?

                    
                        <?php
                        // <input type="number" name="menge">, eingegeben: 3
                        $menge = $_POST["menge"];

                        if ($menge === 3) {
                            echo "Drei Stück";
                        } else {
                            echo "Etwas anderes";
                        }

Etwas anderes - Formularwerte sind immer Strings: "3" === 3 ist false (vgl. Lektion 02)

Verarbeitung

Eingaben aufbereiten

                    
                        <?php
                        $name   = trim($_POST["name"] ?? "");
                        $menge  = (int) ($_POST["menge"] ?? 0);
                        $extras = $_POST["extras"] ?? [];

                        $total = $menge * $preis;
trim()entfernt Leerzeichen am Anfang und Ende: " Anna " → "Anna"
(int) / (float)wandelt in eine Zahl um: "3" → 3, aber auch "abc" → 0

Ob die Eingaben gültig sind (z.B. Menge grösser als 0), prüfen wir in der nächsten Lektion

Praxis

Eingaben im Formular erhalten

                    
                        <?php
                        $name = trim($_POST["name"] ?? "");
                        $lieferung = $_POST["lieferung"] ?? "abholen";
                        $produkt = (int) ($_POST["produkt"] ?? 0);
                        ?>
                        <input type="text" name="name" value="<?= e($name) ?>">

                        <input type="radio" name="lieferung" value="post"
                            <?= $lieferung === "post" ? "checked" : "" ?>> Per Post
                        <option value="2" <?= $produkt === 2 ? "selected" : "" ?>>
                            Karotten</option>

Sonst ist das Formular nach dem Absenden wieder leer. Text → value, Radio und Checkbox → checked, Option → selected

Sicherheit

Formulardaten kommen von aussen

Immer maskieren

Eingaben bei der Ausgabe immer mit e() / htmlspecialchars() ausgeben - auch im value-Attribut

Nichts glauben

Mit den DevTools kann jeder ein value ändern, Optionen ergänzen oder maxlength entfernen

Auch <input type="hidden"> ist nur unsichtbar, nicht geschützt - z.B. nie einen Preis in einem versteckten Feld mitschicken

Quiz

Was passiert hier?

                    
                        <form method="post">
                            <input type="checkbox" name="agb" value="ja"> AGB gelesen
                            <button>Bestellen</button>
                        </form>
                        <?php
                        if ($_SERVER["REQUEST_METHOD"] === "POST") {
                            echo "AGB: " . $_POST["agb"];
                        }

Der Benutzer klickt auf "Bestellen", ohne die Checkbox anzuhaken

Warnung Undefined array key "agb", danach wird AGB: ausgegeben - besser isset($_POST["agb"])

Achtung

Typische Fehler

name fehlt

Das Feld wird nicht gesendet, obwohl es eine id hat

Falsches Array

method="post", aber im Code $_GET gelesen (oder umgekehrt)

Checkbox ohne isset()

Nicht angehakte Checkboxen fehlen in $_POST → Warnung

=== mit Zahl

$_POST["menge"] === 3 ist nie wahr - zuerst mit (int) umwandeln

TL;DR

  • action = wohin, method = wie, name = Schlüssel in $_GET / $_POST
  • GET für Abfragen (Werte in der URL), POST für Daten, die etwas verändern
  • $_SERVER["REQUEST_METHOD"] === "POST" prüft, ob das Formular abgeschickt wurde
  • Checkboxen und Radio-Buttons fehlen, wenn nichts gewählt ist - isset() bzw. ?? verwenden; name="x[]" ergibt ein Array
  • Alle Werte sind Strings und kommen von aussen: aufbereiten, mit e() ausgeben - nächste Lektion: Validierung

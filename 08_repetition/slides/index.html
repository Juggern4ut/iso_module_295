Lektion 04

Welche Schleife wann?

Schleife Einsatz
forAnzahl Durchläufe ist bekannt
foreachjedes Element eines Arrays durchgehen
whilesolange eine Bedingung zutrifft (evtl. 0 Durchläufe)
do-whilewie while, aber mindestens 1 Durchlauf

Endlosschleife: Wird die Bedingung nie false, läuft die Schleife ewig. break bricht ab, continue überspringt einen Durchlauf.

Lektion 05

Funktionen

                    
                        <?php
                        function greet(string $name, string $greeting = "Hallo"): string
                        {
                            return "$greeting, $name!";
                        }

                        echo greet("Mia");                       // Hallo, Mia!
                        echo greet("Tim", "Servus");             // Servus, Tim!
                        echo greet(greeting: "Hoi", name: "Ana"); // Hoi, Ana!

return gibt einen Wert zurück, echo gibt nur aus. Optionale Parameter stehen immer am Ende.

Lektion 05

Scope und Referenzen

Gültigkeitsbereich

  • Variablen in einer Funktion sind lokal
  • Äussere Variablen sind in der Funktion nicht sichtbar
  • Ausnahmen: global, static

Value vs. Reference

  • Standard: die Funktion erhält eine Kopie
  • Mit &$param wird das Original verändert
Lektion 05

Funktionen ohne Namen

Anonyme Funktion


$k = 3;
$times = function ($n) use ($k) {
    return $n * $k;
};

Arrow Function


$k = 3;
$times = fn($n) => $n * $k;

Häufig als Argument, z.B. array_map(fn($n) => $n * 2, $numbers). Arrow Functions sehen äussere Variablen automatisch, anonyme Funktionen brauchen use.

Quiz

Was gibt dieser Code aus?

                    
                        <?php
                        function addOne($n) { $n++; }
                        function addOneRef(&$n) { $n++; }

                        $x = 5;
                        addOne($x);
                        echo $x;     // ?
                        addOneRef($x);
                        echo $x;     // ?

Lektion 06

Klassen und Objekte

Klasse (Bauplan)


class Account
{
    public function __construct(
        private string $owner,
        private float $balance = 0
    ) {}

    public function deposit(float $amount): void
    {
        $this->balance += $amount;
    }

    public function getBalance(): float
    {
        return $this->balance;
    }
}

Objekt (Instanz)


$account = new Account("Mia");
$account->deposit(50);
echo $account->getBalance();
// 50

$this zeigt in einer Methode auf das eigene Objekt

Lektion 06

OOP im Überblick

Sichtbarkeit

  • public - überall
  • protected - Klasse + Kinder
  • private - nur die Klasse

Vererbung

  • extends übernimmt alles
  • Methoden überschreiben
  • parent:: ruft die Elternklasse auf

Vorgaben

  • abstract: kein new möglich
  • interface: welche Methoden es geben muss

static und const gehören zur Klasse, nicht zum Objekt - Zugriff mit Klasse::name.

Quiz

Was passiert hier?

                    
                        <?php
                        class Account
                        {
                            public function __construct(
                                private string $owner,
                                private float $balance = 0
                            ) {}
                            // deposit() und getBalance() wie auf der vorherigen Folie
                        }

                        $account = new Account("Mia");
                        $account->deposit(20);
                        echo $account->balance;

Fatal Error: $balance ist private - Zugriff von aussen nur über getBalance()

Lektion 07

Typisches Muster: Login

                    
                        <?php
                        session_start();

                        if (($_GET["user"] ?? "") === "admin") {
                            session_regenerate_id(true);
                            $_SESSION["username"] = "admin";
                        }

                        if (isset($_SESSION["username"])) {
                            echo "Willkommen, " . $_SESSION["username"];
                        } else {
                            echo "Bitte einloggen";
                        }

Typische Fehler

Syntax

  • ; am Zeilenende vergessen
  • $ vor dem Variablennamen vergessen
  • . statt + für Texte
  • = statt === in einer Bedingung

Logik

  • return in einer Funktion vergessen
  • $this-> in einer Methode vergessen
  • session_start() nach einer Ausgabe
  • Array-Index ausserhalb des Bereichs

Fehlermeldungen genau lesen: Sie nennen fast immer die Zeile und die Ursache.

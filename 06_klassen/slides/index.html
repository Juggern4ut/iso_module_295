06 - Klassen

Objektorientierte Grundlagen in PHP

  • Die Begriffe Klasse, Objekt und Instanz erklären können

Rückblick

Rückblick: Funktionen

Funktionen

Mit Funktionen haben wir Code gebündelt und wiederverwendbar gemacht

Bisher

Bisher waren Daten (Variablen, Arrays) und Code (Funktionen) getrennte Dinge

Heute verbinden wir beides: Klassen bündeln Daten und die dazugehörigen Funktionen gemeinsam

Grundlagen

Wozu Klassen?

Array

Ein Array kann Daten zu einem Produkt speichern - aber die Logik dazu (z.B. Preis berechnen) liegt woanders im Code

Klasse

Eine Klasse beschreibt einen eigenen Datentyp, der Eigenschaften (Daten) und Methoden (Verhalten) an einem Ort zusammenfasst 

                    
                        <?php
                        // Bisher: Daten und Logik getrennt
                        $product = ["name" => "Apfel", "price" => 0.50];

                        function printInfo($product) {
                            echo $product["name"] . ": " . $product["price"] . " CHF";
                        }

Das Konzept kennen Sie bereits aus anderen Sprachen - in PHP gilt dasselbe Prinzip

Grundlagen

Klasse, Objekt und Instanz

Klasse

Eine Klasse ist ein Bauplan - sie legt fest, welche Eigenschaften und Methoden ein Ding dieses Typs hat

Objekt

Ein Objekt ist ein konkretes Ding, das nach diesem Bauplan erzeugt wurde - man sagt auch, es ist eine Instanz der Klasse

Viele Objekte

Aus einer Klasse lassen sich beliebig viele, unabhängige Objekte erzeugen

Grundlagen

Eine Klasse definieren

Syntax

Mit dem Schlüsselwort class, gefolgt vom Namen (meist PascalCase) und einem Codeblock in geschweiften Klammern

Eigenschaften

Eigenschaften (properties) sind Variablen innerhalb der Klasse - sie speichern die Daten eines Objekts 

                    
                        <?php
                        class Product {
                            public string $name;
                            public float $price;
                        }
                        // Bis hierhin passiert noch nichts -
                        // die Klasse wurde nur definiert
Grundlagen

Ein Objekt erzeugen

new

Mit dem Schlüsselwort new gefolgt vom Klassennamen wird ein neues Objekt (eine Instanz) erzeugt

->

Auf Eigenschaften greift man mit dem Pfeil-Operator -> zu 

                    
                        <?php
                        class Product {
                            public string $name;
                            public float $price;
                        }

                        $apple = new Product();
                        $apple->name = "Apfel";
                        $apple->price = 0.50;

                        echo $apple->name; // "Apfel"
Grundlagen

Mehrere, unabhängige Objekte

Jedes Objekt hat seine eigenen Werte für die Eigenschaften - eine Änderung an einem Objekt wirkt sich nicht auf ein anderes aus 

                    
                        <?php
                        $apple = new Product();
                        $apple->name = "Apfel";
                        $apple->price = 0.50;

                        $bread = new Product();
                        $bread->name = "Brot";
                        $bread->price = 3.20;

                        echo $apple->name; // "Apfel"
                        echo $bread->name; // "Brot"
Grundlagen

Methoden

Verhalten

Eine Methode ist eine Funktion innerhalb einer Klasse - sie beschreibt das Verhalten eines Objekts

Aufruf

Aufgerufen wird sie ebenfalls mit dem Pfeil-Operator -> 

                    
                        <?php
                        class Product {
                            public string $name;
                            public float $price;

                            public function printInfo() {
                                echo $this->name . ": " . $this->price . " CHF";
                            }
                        }

                        $apple = new Product();
                        $apple->name = "Apfel";
                        $apple->price = 0.50;
                        $apple->printInfo(); // "Apfel: 0.5 CHF"
Grundlagen

$this - Verweis auf das aktuelle Objekt

Innerhalb einer Methode zeigt $this immer auf das Objekt, über welches die Methode gerade aufgerufen wurde 

                    
                        <?php
                        $apple->printInfo(); // $this zeigt hier auf $apple
                        $bread->printInfo(); // $this zeigt hier auf $bread

Damit greift eine Methode auf die Eigenschaften ihres eigenen Objekts zu

Grundlagen

Der Konstruktor __construct()

Automatisch

Die Methode __construct() wird automatisch aufgerufen, sobald ein Objekt mit new erzeugt wird

Zweck

Sie dient dazu, die Eigenschaften direkt bei der Erzeugung zu setzen - statt sie danach einzeln zuzuweisen 

                    
                        <?php
                        class Product {
                            public string $name;
                            public float $price;

                            public function __construct($name, $price) {
                                $this->name = $name;
                                $this->price = $price;
                            }
                        }

                        $apple = new Product("Apfel", 0.50);
                        echo $apple->name; // "Apfel"
PHP 8

Constructor Property Promotion

Seit PHP 8 können Eigenschaften direkt in der Parameterliste des Konstruktors deklariert werden - Deklaration und Zuweisung passieren dann in einem Schritt 

                    
                        <?php
                        class Product {
                            public function __construct(
                                public string $name,
                                public float $price
                            ) {}
                        }

                        $apple = new Product("Apfel", 0.50);
                        echo $apple->name; // "Apfel"

Spart Schreibarbeit, das Verhalten ist identisch zur vorherigen Folie

Kapselung

Sichtbarkeit: public und private

public

public - von überall zugreifbar, auch von aussen über ->

private

private - nur innerhalb derselben Klasse zugreifbar, schützt Daten vor unerlaubtem Zugriff von aussen 

                    
                        <?php
                        class Product {
                            public function __construct(
                                public string $name,
                                private float $price
                            ) {}
                        }

                        $apple = new Product("Apfel", 0.50);
                        echo $apple->name;  // "Apfel" - erlaubt
                        echo $apple->price; // Fehler: $price ist private
Kapselung

Sichtbarkeit: protected

Erlaubt

protected - zugreifbar innerhalb der eigenen Klasse und in davon abgeleiteten Klassen (Vererbung, siehe später)

Nicht erlaubt

Von aussen (über ->) ist der Zugriff, wie bei private, nicht erlaubt

Kapselung

Getter und Setter

Zugriff über Methoden

Da private-Eigenschaften von aussen nicht direkt zugreifbar sind, definiert man öffentliche Methoden dafür - Getter zum Lesen, Setter zum Schreiben

Prüfen

Ein Setter kann zusätzlich Werte prüfen, bevor er sie übernimmt

Kapselung

Getter und Setter: Beispiel

                    
                        <?php
                        class Product {
                            public function __construct(
                                public string $name,
                                private float $price
                            ) {}

                            public function getPrice(): float {
                                return $this->price;
                            }

                            public function setPrice(float $price): void {
                                if ($price >= 0) {
                                    $this->price = $price;
                                }
                            }
                        }

                        $apple = new Product("Apfel", 0.50);
                        echo $apple->getPrice(); // 0.5
                        $apple->setPrice(0.80);
                        echo $apple->getPrice(); // 0.8
Quiz

Was gibt dieser Code aus?

                    
                        <?php
                        class Account {
                            public function __construct(private float $balance) {}

                            public function getBalance(): float {
                                return $this->balance;
                            }

                            public function setBalance(float $balance): void {
                                if ($balance >= 0) {
                                    $this->balance = $balance;
                                }
                            }
                        }

                        $account = new Account(100);
                        $account->setBalance(-50);
                        echo $account->getBalance();

100 - der Setter lehnt den negativen Wert ab, der Kontostand bleibt unverändert

Statisch

Statische Eigenschaften

Gehört der Klasse

Eine static-Eigenschaft gehört der Klasse selbst, nicht einem einzelnen Objekt - alle Objekte teilen sich denselben Wert

Zugriff

Zugriff innerhalb der Klasse mit self::$name 

                    
                        <?php
                        class Product {
                            public static int $count = 0;

                            public function __construct(public string $name) {
                                self::$count++;
                            }
                        }

                        $apple = new Product("Apfel");
                        $bread = new Product("Brot");
                        echo Product::$count; // 2
Quiz

Was gibt dieser Code aus?

                    
                        <?php
                        class Counter {
                            public static int $total = 0;
                            public int $mine = 0;

                            public function increment(): void {
                                self::$total++;
                                $this->mine++;
                            }
                        }

                        $a = new Counter();
                        $b = new Counter();
                        $a->increment();
                        $a->increment();
                        $b->increment();
                        echo $a->mine . " " . $b->mine . " " . Counter::$total;

2 1 3 - $mine gehört jedem Objekt einzeln, $total teilen sich alle Objekte

Statisch

Statische Methoden

Aufruf

Eine static-Methode wird über den Klassennamen aufgerufen, nicht über ein Objekt - Klasse::methode()

Kein $this

Innerhalb einer statischen Methode gibt es kein $this, da kein konkretes Objekt vorliegt 

                    
                        <?php
                        class Product {
                            private static int $count = 0;

                            public function __construct(public string $name) {
                                self::$count++;
                            }

                            public static function getCount(): int {
                                return self::$count;
                            }
                        }

                        new Product("Apfel");
                        new Product("Brot");
                        echo Product::getCount(); // 2
Statisch

Klassenkonstanten

const

Mit const definiert man einen Wert, der sich nie ändert - z.B. einen Steuersatz

Zugriff

Zugriff innerhalb der Klasse mit self::NAME, von aussen mit Klasse::NAME 

                    
                        <?php
                        class Product {
                            public const TAX_RATE = 0.077;

                            public function __construct(
                                public string $name,
                                public float $price
                            ) {}

                            public function priceWithTax(): float {
                                return $this->price * (1 + self::TAX_RATE);
                            }
                        }

                        $apple = new Product("Apfel", 0.50);
                        echo $apple->priceWithTax(); // 0.5385
                        echo Product::TAX_RATE;      // 0.077
Vererbung

Vererbung mit extends

Erben

Eine Klasse kann alle Eigenschaften und Methoden einer anderen Klasse erben - die neue Klasse muss diese nicht selbst nochmals definieren

Begriffe

Die ursprüngliche Klasse heisst Basisklasse (Eltern- klasse), die neue abgeleitete Klasse (Kindklasse) 

                    
                        <?php
                        class SaleProduct extends Product {
                            // erbt $name, $price, priceWithTax(), ...
                            public function __construct(
                                string $name,
                                float $price,
                                public float $discount
                            ) {
                                parent::__construct($name, $price);
                            }
                        }

                        $sale = new SaleProduct("Apfel", 0.50, 0.2);
                        echo $sale->priceWithTax(); // geerbt von Product
Vererbung

parent::

Mit parent:: ruft man gezielt eine Methode der Basisklasse auf - z.B. deren Konstruktor, wie auf der vorherigen Folie

So lässt sich Code der Basisklasse wiederverwenden, statt ihn zu duplizieren

Vererbung

Methoden überschreiben (Overriding)

Neu definieren

Eine abgeleitete Klasse kann eine geerbte Methode mit demselben Namen neu definieren - die eigene Version gilt dann

parent::methode()

Mit parent::methode() lässt sich innerhalb der neuen Version trotzdem die ursprüngliche Methode mit aufrufen 

                    
                        <?php
                        class SaleProduct extends Product {
                            public function __construct(
                                string $name, float $price, public float $discount
                            ) {
                                parent::__construct($name, $price);
                            }

                            public function priceWithTax(): float {
                                $reducedPrice = $this->price * (1 - $this->discount);
                                return $reducedPrice * (1 + self::TAX_RATE);
                            }
                        }

                        $sale = new SaleProduct("Apfel", 0.50, 0.2);
                        echo $sale->priceWithTax(); // eigene, überschriebene Version
Vererbung

Abstrakte Klassen

Kein new

Eine abstract-Klasse kann nicht direkt mit new erzeugt werden - sie dient nur als Basis für andere Klassen

Abstrakte Methoden

Sie kann abstrakte Methoden enthalten - diese haben keinen Codeblock, jede abgeleitete Klasse muss sie implementieren 

                    
                        <?php
                        abstract class Shape {
                            abstract public function calculateArea(): float;

                            public function printArea(): void {
                                echo "Fläche: " . $this->calculateArea();
                            }
                        }

                        $shape = new Shape(); // Fehler: abstrakte Klasse
Vererbung

Abstrakte Klasse implementieren

Umsetzung

Konkrete Klassen erben von der abstrakten Klasse und liefern die Umsetzung der abstrakten Methode

Geerbt

Nicht-abstrakte Methoden (wie printArea()) werden ganz normal geerbt 

                    
                        <?php
                        class Circle extends Shape {
                            public function __construct(private float $radius) {}

                            public function calculateArea(): float {
                                return M_PI * $this->radius ** 2;
                            }
                        }

                        $circle = new Circle(3);
                        $circle->printArea(); // "Fläche: 28.27..."
Vererbung

Interfaces

interface

Ein interface schreibt vor, welche Methoden eine Klasse haben muss - ohne selbst eine Umsetzung vorzugeben

implements

Eine Klasse setzt ein Interface mit implements um und kann dabei auch gleichzeitig von einer Klasse erben 

                    
                        <?php
                        interface Describable {
                            public function describe(): string;
                        }

                        class Circle extends Shape implements Describable {
                            public function __construct(private float $radius) {}

                            public function calculateArea(): float {
                                return M_PI * $this->radius ** 2;
                            }

                            public function describe(): string {
                                return "Kreis mit Radius " . $this->radius;
                            }
                        }
PHP 8.1

Unveränderliche Eigenschaften mit readonly

Nur einmal setzen

Seit PHP 8.1 kann eine Eigenschaft als readonly markiert werden - sie darf nur einmal, direkt im Konstruktor, gesetzt werden

Danach: Fehler

Ein späterer Schreibversuch löst einen Fehler aus - nützlich für Werte, die sich nach der Erzeugung nicht mehr ändern sollen 

                    
                        <?php
                        class Point {
                            public function __construct(
                                public readonly float $x,
                                public readonly float $y
                            ) {}
                        }

                        $p = new Point(3, 4);
                        echo $p->x;  // 3
                        $p->x = 10;  // Fehler: readonly-Eigenschaft
Praxis

Der instanceof-Operator

Mit instanceof prüft man, ob ein Objekt von einer bestimmten Klasse (oder einem Interface) ist 

                    
                        <?php
                        $shapes = [new Circle(3), new Product("Apfel", 0.5)];

                        foreach ($shapes as $item) {
                            if ($item instanceof Shape) {
                                $item->printArea();
                            }
                        }
                        // nur der Kreis wird ausgegeben - Product ist kein Shape

Praktisch, wenn ein Array Objekte verschiedener, verwandter Klassen enthält

TL;DR

  • Eine Klasse ist ein Bauplan für Objekte - mit new wird daraus eine konkrete Instanz erzeugt
  • Eigenschaften und Methoden gehören zusammen; $this zeigt innerhalb einer Methode auf das eigene Objekt
  • public, private und protected steuern die Sichtbarkeit - Getter/Setter kapseln private Daten
  • static gehört der Klasse, nicht dem Objekt; const definiert unveränderliche Klassenwerte
  • extends vererbt, abstract-Klassen und interfaces legen fest, was abgeleitete Klassen können müssen

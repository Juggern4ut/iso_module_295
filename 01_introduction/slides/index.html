01 - Einführung in PHP

Grundlagen der serverseitigen Programmierung

Lernziele dieser Lektion

  • Wissen, was PHP ist und wofür es eingesetzt wird
  • Kennen der wichtigsten Fakten zur Geschichte von PHP
  • Verstehen, warum PHP für die serverseitige Entwicklung geeignet ist
  • XAMPP installieren und einen lokalen Server damit betreiben können
  • Ein erstes PHP-Skript schreiben und ausführen können
  • Grundlagen von Variablen in PHP kennen und anwenden können

Was ist PHP?

  • PHP steht für "PHP: Hypertext Preprocessor" (ein rekursives Akronym)
  • Eine serverseitige Skriptsprache
  • Wird auf dem Server ausgeführt, nicht im Browser
  • Der Server liefert dem Client fertiges HTML aus

Was ist PHP?

So läuft eine Anfrage an eine PHP-Seite ab:

  1. Browser fordert eine .php-Datei vom Server an
  2. Der Server führt den PHP-Code aus
  3. PHP generiert daraus HTML (und ggf. CSS/JS)
  4. Der Server sendet das fertige HTML an den Browser zurück

Der Browser sieht niemals den PHP-Quellcode selbst.

Einige Fakten zu PHP

  • PHP wird auf einem sehr grossen Teil aller Websites weltweit eingesetzt
  • Bekannte Systeme, die (teilweise) auf PHP basieren:
    • WordPress
    • Wikipedia (MediaWiki)
    • Facebook (ursprünglich)
    • Shopware

Warum PHP?

  • Einfacher Einstieg: Übersichtliche Syntax, viele Lernressourcen
  • Weit verbreitet: Grosse Community, viele Frameworks (z.B. Laravel, Symfony)
  • Günstiges Hosting: Fast jeder Webhoster unterstützt PHP nativ
  • Direkt in HTML einbettbar: Kein separater Build-Step nötig
  • Plattformunabhängig: Läuft auf Windows, Linux und macOS

Voraussetzungen

Um PHP-Dateien im Browser zu öffnen, benötigen wir einen Webserver mit PHP.

Die einfachste Lösung dafür heisst XAMPP.

Was ist XAMPP?

  • Ein kostenloses Software-Paket, das alles Nötige auf einmal installiert:
    • X - läuft auf Windows, Linux und macOS
    • Apache (Webserver)
    • MariaDB/MySQL (Datenbank)
    • PHP
    • Perl
  • Kein manuelles Einrichten von Apache oder PHP nötig
  • Download unter apachefriends.org

XAMPP installieren

  1. Installer für Ihr Betriebssystem von apachefriends.org herunterladen
  2. Installer ausführen (Standardeinstellungen übernehmen genügt)
  3. Das XAMPP Control Panel öffnen

Server starten

Im XAMPP Control Panel neben Apache auf Start klicken.

  • Das Modul wird grün hinterlegt, sobald es läuft
  • MySQL wird für diese Lektion noch nicht benötigt
  • Mit Stop wird der Server wieder angehalten

Der htdocs-Ordner

Apache liefert nur Dateien aus, die sich im Ordner htdocs befinden.

Windows C:\xampp\htdocs\
macOS /Applications/XAMPP/xamppfiles/htdocs/
Linux /opt/lampp/htdocs/

Erstellen Sie darin einen eigenen Projektordner, z.B. php-intro.

Aufruf im Browser

Läuft Apache, ist jedes Projekt im htdocs-Ordner über localhost erreichbar - ganz ohne Terminal. 

                    
                        http://localhost/php-intro/

Apache sucht im aufgerufenen Ordner automatisch nach einer index.php (oder index.html).

Hello World

PHP-Code wird mit den Tags <?php ... ?> eingeleitet und beendet. 

                    
                        <?php
                        echo "Hallo Welt!";

Speichern Sie diesen Code als index.php in Ihrem Projektordner unter htdocs.

Hello World

  • Im XAMPP Control Panel sicherstellen, dass Apache läuft
  • Im Browser http://localhost/php-intro/ öffnen
  • Ausgabe im Browser: Hallo Welt!

echo gibt Text aus, welcher direkt in das an den Browser gesendete HTML geschrieben wird.

Hello World

PHP kann beliebig oft mit HTML kombiniert werden.

                    
                        <!DOCTYPE html>
                        <html lang="de">
                        <body>
                            <h1>
                                <?php echo "Hallo Welt!"; ?>
                            </h1>
                        </body>
                        </html>

Grundlagen: Variablen

  • Variablen beginnen in PHP immer mit einem $
  • PHP ist lose typisiert - eine Typangabe ist nicht nötig
  • Der Typ wird automatisch anhand des zugewiesenen Wertes bestimmt
  • Variablennamen sind case-sensitive 
                    
                        <?php
                        $name = "Anna";
                        $age = 24;

Grundlagen: Variablen

Die wichtigsten Datentypen in PHP:

string Zeichenkette "Hallo"
int Ganzzahl 24
float Kommazahl 19.95
bool Wahrheitswert true / false
array Liste von Werten [1, 2, 3]
null Kein Wert null

Grundlagen: Variablen

                    
                        <?php
                        $name = "Anna";
                        $age = 24;
                        $isStudent = true;
                        $price = 19.95;

                        echo $name;
                        var_dump($age);
                        var_dump($isStudent);
                        var_dump($price);

var_dump() zeigt Wert und Typ einer Variable an - sehr nützlich beim Debuggen.

Grundlagen: Variablen

Texte und Variablen lassen sich auf zwei Arten kombinieren:

                    
                        <?php
                        $name = "Anna";

                        // Konkatenation mit dem Punkt-Operator
                        echo "Hallo " . $name . "!";

                        // String-Interpolation (nur mit doppelten Anführungszeichen)
                        echo "Hallo $name!";
  • . verbindet (konkateniert) Strings
  • Variablen in "..." werden automatisch ersetzt
  • In '...' (einfache Anführungszeichen) funktioniert das nicht

TL;DR

  • PHP ist eine serverseitige Skriptsprache von Rasmus Lerdorf (seit 1994)
  • PHP-Code wird auf dem Server ausgeführt und liefert HTML an den Browser
  • XAMPP liefert Apache, MySQL und PHP als fertiges Paket - Start über das Control Panel
  • Projekte gehören in den htdocs-Ordner und sind dann unter localhost erreichbar
  • PHP-Code steht zwischen <?php ... ?>
  • Variablen beginnen mit $ und sind lose typisiert

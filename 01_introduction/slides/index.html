Grundlagen

Was ist PHP?

PHP steht für "PHP: Hypertext Preprocessor" (ein rekursives Akronym)

Serverseitig

  • Eine serverseitige Skriptsprache
  • Wird auf dem Server ausgeführt, nicht im Browser

Ergebnis

Der Server liefert dem Client fertiges HTML aus

Grundlagen

Was ist PHP?

So läuft eine Anfrage an eine PHP-Seite ab:

1.
Browser fordert eine .php-Datei vom Server an
→
2.
Der Server führt den PHP-Code aus
→
3.
PHP generiert daraus HTML (und ggf. CSS/JS)
→
4.
Der Server sendet das fertige HTML an den Browser zurück

Der Browser sieht niemals den PHP-Quellcode selbst.

Setup

Voraussetzungen

Um PHP-Dateien im Browser zu öffnen, benötigen wir einen Webserver mit PHP.

Die einfachste Lösung dafür heisst XAMPP.

Setup

Was ist XAMPP?

Paket

Ein kostenloses Software-Paket, das alles Nötige auf einmal installiert:

  • X - läuft auf Windows, Linux und macOS
  • Apache (Webserver)
  • MariaDB/MySQL (Datenbank)
  • PHP
  • Perl

Vorteil

  • Kein manuelles Einrichten von Apache oder PHP nötig
  • Download unter apachefriends.org

Setup

Der htdocs-Ordner

Apache liefert nur Dateien aus, die sich im Ordner htdocs befinden.

Windows C:\xampp\htdocs\
macOS /Applications/XAMPP/xamppfiles/htdocs/
Linux /opt/lampp/htdocs/

Erstellen Sie darin einen eigenen Projektordner, z.B. php-intro.

Setup

Aufruf im Browser

Läuft Apache, ist jedes Projekt im htdocs-Ordner über localhost erreichbar - ganz ohne Terminal. 

                    
                        http://localhost/php-intro/

Apache sucht im aufgerufenen Ordner automatisch nach einer index.php (oder index.html).

Grundlagen

Grundlagen: Variablen

Regeln

  • Variablen beginnen in PHP immer mit einem $
  • PHP ist lose typisiert - eine Typangabe ist nicht nötig
  • Der Typ wird automatisch anhand des zugewiesenen Wertes bestimmt
  • Variablennamen sind case-sensitive

Beispiel

                    
                        <?php
                        $name = "Anna";
                        $age = 24;
Grundlagen

Grundlagen: Variablen

Die wichtigsten Datentypen in PHP:

string Zeichenkette "Hallo"
int Ganzzahl 24
float Kommazahl 19.95
bool Wahrheitswert true / false
array Liste von Werten [1, 2, 3]
null Kein Wert null
Praxis

Grundlagen: Variablen

                    
                        <?php
                        $name = "Anna";
                        $age = 24;
                        $isStudent = true;
                        $price = 19.95;

                        echo $name;
                        var_dump($age);
                        var_dump($isStudent);
                        var_dump($price);

var_dump() zeigt Wert und Typ einer Variable an - sehr nützlich beim Debuggen.

Quiz

Was gibt dieser Code aus?

                    
                        <?php
                        $a = "24";
                        $b = 24;
                        $c = 24.0;

                        var_dump($a);
                        var_dump($b);
                        var_dump($c);

string(2) "24" · int(24) · float(24) - der Typ hängt nur vom zugewiesenen Wert ab

Grundlagen

Grundlagen: Variablen

Texte und Variablen lassen sich auf zwei Arten kombinieren: 

                    
                        <?php
                        $name = "Anna";

                        // Konkatenation mit dem Punkt-Operator
                        echo "Hallo " . $name . "!";

                        // String-Interpolation (nur mit doppelten Anführungszeichen)
                        echo "Hallo $name!";

. verbindet (konkateniert) Strings

Variablen in "..." werden automatisch ersetzt

In '...' (einfache Anführungszeichen) funktioniert das nicht

Quiz

Was gibt dieser Code aus?

                    
                        <?php
                        $name = "Anna";
                        $age = 24;

                        echo "Hallo " . $name . "! ";
                        echo 'Alter: $age';

Hallo Anna! Alter: $age - in einfachen Anführungszeichen wird $age nicht ersetzt

TL;DR

  • PHP ist eine serverseitige Skriptsprache von Rasmus Lerdorf (seit 1994)
  • PHP-Code wird auf dem Server ausgeführt und liefert HTML an den Browser
  • XAMPP liefert Apache, MySQL und PHP als fertiges Paket - Start über das Control Panel
  • Projekte gehören in den htdocs-Ordner und sind dann unter localhost erreichbar
  • PHP-Code steht zwischen <?php ... ?>
  • Variablen beginnen mit $ und sind lose typisiert
